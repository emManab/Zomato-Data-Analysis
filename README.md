This project performs detailed analysis and visualization on a comprehensive Zomato restaurant dataset to extract meaningful customer behavior insights and support data-driven decisions. The analysis answers key business questions such as:

Most popular restaurant types: Identifying which cuisine types or categories customers order from most frequently.

Customer votes by category: Counting and comparing customer votes across different restaurant types.

Rating distributions: Finding the most common ratings that restaurants have received.

Couples’ online spending behavior: Calculating the average spending per online order for couples, based on observed data patterns.

Comparison of ordering modes: Determining which mode (online or offline) receives higher customer ratings.

Offline ordering trends: Identifying which types of restaurants receive more offline orders to inform targeted promotions and offers.
